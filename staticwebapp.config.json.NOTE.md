# ⚠️ This file is NOT used for Azure App Service

**`staticwebapp.config.json` is only for Azure Static Web Apps.**

For **Azure App Service**, Easy Auth is configured through the Azure Portal, not via this config file.

You can:
- **Delete this file** if you're only using Azure App Service
- **Keep it** if you might use Azure Static Web Apps in the future
- **Ignore it** - it won't affect your App Service deployment

See `AZURE_APP_SERVICE_EASY_AUTH_SETUP.md` for App Service setup instructions.
